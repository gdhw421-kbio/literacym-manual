# 리터러시M 사용자 매뉴얼 사이트

환자용 앱 **리터러시M(LiteracyM)** 의 회원가입 · 앱 설치 · 로그인 안내 매뉴얼입니다.
기기(안드로이드 / 아이폰) × 언어(영어 / 몽골어) 조합으로 4종을 제공합니다.

> 2026년 「ICT기반 외국인환자 사전상담·사후관리 지원 사업」 (한국보건산업진흥원)
> KBIOHEALTHCARE · KYUNG HEE UNIVERSITY MEDICAL CENTER · MEDIJOY

| 페이지 | 파일 |

페이지당 STEP 1개이며, `한국어 숨기기` 버튼으로 현지어만 남긴 상태로도 인쇄할 수 있습니다.

## 내용을 수정하는 방법

**HTML 파일을 직접 고치지 마세요.** 모든 내용은 `manual-project.json` 한 곳에 있고,
관리자 페이지(`admin.html`)로 편집합니다.

1. `admin.html` 을 브라우저에서 엽니다 (로컬 파일로 실행)
2. `JSON 불러오기` → 이 저장소의 `manual-project.json` 선택
3. 편집 — 페이지 추가·삭제·순서변경, 문구 수정, 스크린샷 교체, 새 언어판 추가
4. `프로젝트 저장` → `manual-project.json` 내려받기
5. `HTML 내보내기` → `전체 문서 + 첫 화면` → HTML 5개 내려받기
6. 내려받은 6개 파일을 이 저장소에 업로드하고 커밋 → Netlify가 자동 배포

자세한 절차는 `deploy-guide.md` 참고.

### 스크린샷

스크린샷은 **문서별로 따로 관리**됩니다. 같은 STEP이라도 영어판과 몽골어판에
서로 다른 화면(각 언어로 표시된 앱 화면)을 넣을 수 있습니다.
업로드 시 가로 460px · JPEG로 자동 축소되며, 인쇄 시 세로 120mm로 배치됩니다.

## 파일 구조

### 배포되는 파일

```
index.html                          첫 화면
literacym-guide-*.html              가이드 4종 (이미지 포함, 단일 파일)
manual-project.json                 편집 원본 데이터 — 모든 내용의 유일한 출처
```

### 편집 도구 (배포하지 않음)

```
admin.html                          관리자 페이지. 로컬에서 실행
```

### 자동 빌드용 (선택)

`manual-project.json` 만 올리고 HTML은 Netlify가 생성하게 하려면 아래 파일들이 필요합니다.

```
build.mjs                           빌드 스크립트
render.js                           HTML 생성 로직 (admin.html과 동일한 코드)
guide.css                           가이드 스타일 + 16:9 인쇄 규칙
guide.js                            가이드 동작 (한국어 토글, 인쇄, 이미지 확대)
index.css                           첫 화면 스타일
```

Netlify 설정 — **Build command** `node build.mjs` / **Publish directory** `dist`

`render.js` 는 관리자 페이지와 빌드 스크립트가 **똑같이** 사용합니다.
따라서 관리자 페이지에서 내보낸 파일과 Netlify가 생성한 파일은 바이트 단위로 동일합니다.

## 주의사항

- **파일명을 바꾸지 마세요.** `index.html` 이 가이드 4개를 이 이름으로 참조합니다.
  이름을 바꾸려면 관리자 페이지의 `문서 설정 → 내보낼 파일명` 과 `기기 전환 안내` 를 함께 수정하세요.
- 관리자 페이지는 **자동 저장되지 않습니다.** 편집 후 반드시 `프로젝트 저장` 을 누르세요.
- `manual-project.json` 이 사실상의 원본입니다. 이 파일을 잃으면 처음부터 다시 만들어야 하니
  항상 저장소에 최신본을 올려두세요.

- 아이폰 STEP 8 권한 항목이 한국어로 섞여 있던 부분을 몽골어로 번역

  실제로는 안드로이드에서도 권한 요청이 표시되므로 페이지 추가 검토가 필요합니다.
